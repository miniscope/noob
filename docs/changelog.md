# Changelog

Each package in the monorepo is versioned and released independently, and keeps
its own changelog.

Unreleased changes live as fragments in
[`changelog/<package>/`](https://github.com/miniscope/noob/tree/main/changelog)
until a release folds them in - preview them with `pdm run changelog draft`.
